Framework e Menu de Mods da Comunidade / Community Mod Framework - 1.2 Echinades
===WORKSHOP_DESCRIPTION===
[i]You are on the DeepL-Generated Portuguese (Brazil) Page. [url=https://steamcommunity.com/sharedfiles/filedetails/?id=$item-id$&l=english]Click here for the Native English Page.[/url][/i]

O [b]Community Mod Framework (CMF)[/b] é um mod utilitário que visa melhorar a interoperabilidade entre mods, fornecendo ferramentas para criadores de mods desenvolverem novos recursos.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]O CMF deve ser carregado primeiro na sua ordem de carregamento de mods.[/b]

Qualquer dúvida, sinta-se à vontade para entrar em contato no Discord do EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Recursos[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]Community Mod Menu (CMM):[/url][/b] Um menu de mods compartilhado dentro do jogo. Autores de mods registram configurações dinamicamente através de uma API simples, sem a necessidade de construir uma interface de configurações personalizada.
  [list]
   [*]Configurações de alternância (toggle), botão, numérico, controle deslizante (clique duplo para arrastar), menu suspenso (dropdown), texto (apenas singleplayer) e lista
   [*]Abas por mod, grupos e busca
   [*]Configurações globais com edição exclusiva para o host no multiplayer
   [*]Redefinir para o Padrão
   [*]Janela arrastável
   [*]Pode ser aberto pelo menu de escape no jogo. Ou via atalho ('m' por padrão, pode ser reatribuído).
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: ferramenta baseada em navegador para criar seu menu de mod
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]Alertas Personalizados:[/url][/b] Crie e exiba alertas personalizados na barra de alertas através de chaves de localização.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]Barra de Ação:[/url][/b] Adicione botões personalizados na barra de ação com chaves de localização.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]Transferência de País:[/url][/b] As configurações do CMM são transferidas automaticamente ao mudar de país (trocas de tag, herança, etc.).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]Gatilho is_host:[/url][/b] Verifica se o país atual é controlado pelo jogador host.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]Alternância de Ferramentas Irrestritas:[/url][/b] Restrinja recursos específicos através da configuração "Habilitar Ferramentas Irrestritas" (gatilho cmf_can_use_unrestricted_tools, flag por configuração cmm_set_requires_unrestricted_tools_enabled). Disponível apenas para o host no multiplayer.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]Efeito cmf_suppress:[/url][/b] Suprima avisos da engine de "usado mas nunca definido" e "definido mas nunca usado" com uma única chamada de efeito.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]Macros de GUI:[/url][/b] Macros de operadores lógicos Nand, Nor e Xor.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]Ganchos (Hooks) de On-Action:[/url][/b] Ganchos de início de jogo pós-lobby e carregamento de save (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) com variantes para países de jogadores. Também inclui pulsos anuais e mensais compartilhados para jogadores humanos.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/cmf_change_variable_map-Effect]Utilitários de Mapa de Variáveis:[/url][/b] Auxiliares de mutação segura de mapa de variáveis (cmf_change_variable_map e variantes locais/globais) que lidam com remoção-e-adição de forma atômica.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]Log de Ações de Mods:[/url][/b] Registro global dentro do jogo para gravar ações de mods (ex: ações de ferramentas do host no multiplayer, já que o log não pode ser limpo no MP).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Um conjunto complementar de ferramentas de desenvolvimento, como modelo de mod, uploader da oficina e tradutor de mods.
[/list]
