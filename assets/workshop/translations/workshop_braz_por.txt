[h1]Community Mod Framework[/h1]

O [b]Community Mod Framework (CMF)[/b] é um mod de utilitário compartilhado que fornece um menu de mods e ferramentas de modding para o Europa Universalis V.

[b]O CMF deve ser carregado primeiro na sua ordem de carregamento de mods.[/b]

[h1]Recursos[/h1]
[list]
[*][b]Community Mod Menu (CMM):[/b] Uma janela compartilhada de configurações de mods dentro do jogo. Autores de mods registram configurações dinamicamente através de uma API simples — sem a necessidade de criar uma interface de usuário de configurações personalizada.
  [list]
   [*]Configurações de alternância (toggle), botão, numérico, controle deslizante (clique duplo para arrastar), menu suspenso (dropdown), texto (apenas singleplayer) e lista.
   [*]Abas por mod, grupos e busca.
   [*]Configurações globais com edição em multiplayer exclusiva para o anfitrião (host).
   [*]Redefinir para os padrões (Reset to Defaults).
   [*]Ferramenta CMM Visual Editor para configuração sem necessidade de código.
  [/list]
[*][b]Alertas Personalizados:[/b] Crie e exiba alertas personalizados na barra de alertas através de chaves de localização.
[*][b]Barra de Ação:[/b] Adicione botões personalizados na barra de ação com chaves de localização.
[*][b]Trigger is_host:[/b] Verifica se o país atual é controlado pelo jogador anfitrião.
[*][b]Efeito cmf_suppress:[/b] Suprime os avisos da engine de "usado, mas nunca definido" e "definido, mas nunca usado" com uma única chamada de efeito.
[*][b]Hook de País de Jogador:[/b] on_actions compartilhados (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse) que são acionados para o país de cada jogador humano em pulsos anuais e mensais (um pouco mais eficiente do que cada mod verificar os jogadores individualmente).
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Um conjunto complementar de ferramentas de desenvolvimento, como um modelo de mod, uploader para a oficina e tradutor de mod.
[/list]
