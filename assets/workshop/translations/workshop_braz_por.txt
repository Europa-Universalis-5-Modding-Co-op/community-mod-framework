Framework e Menu de Mods da Comunidade / Community Mod Framework & Menu
===WORKSHOP_DESCRIPTION===

O [b]Community Mod Framework (CMF)[/b] é um mod utilitário que visa melhorar a interoperabilidade entre mods, fornecendo ferramentas aos modders para a criação de novos recursos.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/banner.png[/img]

[b]O CMF deve ser carregado primeiro na sua ordem de carregamento de mods.[/b]

Qualquer dúvida, sinta-se à vontade para entrar em contato no Discord do EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Recursos[/h1]
[list]
 [*][b]Community Mod Menu (CMM):[/b] Um menu de mods compartilhado dentro do jogo. Autores de mods registram configurações dinamicamente através de uma API simples — sem a necessidade de construir uma interface de usuário de configurações personalizada.
  [list]
   [*]Configurações de alternância (toggle), botão, numérico, controle deslizante (clique duplo para arrastar), menu suspenso (dropdown), texto (apenas singleplayer) e lista
   [*]Abas por mod, grupos e busca
   [*]Configurações globais com edição exclusiva pelo host no multiplayer
   [*]Redefinir para os Padrões
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url] — ferramenta baseada em navegador para criar o seu menu de mod
  [/list]
 [*][b]Alertas Personalizados:[/b] Crie e exiba alertas personalizados na barra de alertas através de chaves de localização.
 [*][b]Barra de Ação:[/b] Adicione botões personalizados à barra de ação com chaves de localização.
 [*][b]Trigger is_host:[/b] Verifica se o país atual é controlado pelo jogador host.
 [*][b]Efeito cmf_suppress:[/b] Suprime avisos da engine do tipo "used but never set" e "set but never used" com uma única chamada de efeito.
 [*][b]Hooks de On-Action:[/b] Hooks de início de jogo pós-lobby e de carregamento de save (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) com variantes para países de jogadores. Também inclui pulsos anuais e mensais compartilhados para jogadores humanos.
 [*][b]Utilitários de Variable Map:[/b] Auxiliares de mutação segura de mapas de variáveis (cmf_change_variable_map e variantes locais/globais) que lidam com a remoção e adição de forma atômica.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Um conjunto complementar de ferramentas de desenvolvimento, como modelo de mod, enviador para a oficina (workshop uploader) e tradutor de mod.
[/list]
