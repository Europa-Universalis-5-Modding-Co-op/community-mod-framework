Framework e Menu de Mods da Comunidade / Community Mod Framework & Menu
===WORKSHOP_DESCRIPTION===
[i]You are on the DeepL-Generated Portuguese (Brazil) Page. [url=https://steamcommunity.com/sharedfiles/filedetails/?id=$item-id$&l=english]Click here for the Native English Page.[/url][/i]

O [b]Community Mod Framework (CMF)[/b] é um mod utilitário que visa melhorar a interoperabilidade entre mods, fornecendo aos modders ferramentas para criar novos recursos.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/banner.png[/img]

[b]O CMF deve ser carregado primeiro na sua ordem de carregamento de mods.[/b]

Qualquer dúvida, sinta-se à vontade para entrar em contato no Discord do EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Recursos[/h1]
[list]
 [*][b]Community Mod Menu (CMM):[/b] Um menu de mods compartilhado dentro do jogo. Autores de mods registram configurações dinamicamente através de uma API simples — sem a necessidade de construir uma UI de configurações personalizada.
  [list]
   [*]Configurações de alternador (toggle), botão, numérico, controle deslizante (clique duplo para arrastar), menu suspenso, texto (apenas um jogador) e lista.
   [*]Abas por mod, grupos e busca.
   [*]Configurações globais com edição apenas para o anfitrião (host) no multijogador.
   [*]Redefinir para os Padrões.
   [*]Janela arrastável.
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url] — ferramenta baseada em navegador para criar seu menu de mods.
  [/list]
 [*][b]Alertas Personalizados:[/b] Crie e exiba alertas personalizados na barra de alertas através de chaves de localização.
 [*][b]Barra de Ações:[/b] Adicione botões personalizados à barra de ações com chaves de localização.
 [*][b]Transferência de País:[/b] As configurações do CMM são transferidas automaticamente ao trocar de país (trocas de tag, herança, etc.).
 [*][b]Gatilho is_host:[/b] Verifica se o país atual é controlado pelo jogador anfitrião.
 [*][b]Efeito cmf_suppress:[/b] Suprime avisos do motor de "usado mas nunca definido" e "definido mas nunca usado" com uma única chamada de efeito.
 [*][b]Ganchos de On-Action:[/b] Ganchos para início de jogo pós-lobby e carregamento de salvamento (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) com variantes para o país do jogador. Também inclui pulsos anuais e mensais compartilhados para jogadores humanos.
 [*][b]Utilitários de Mapas de Variáveis:[/b] Auxiliares para mutação segura de mapas de variáveis (cmf_change_variable_map e variantes locais/globais) que lidam com a remoção e adição de forma atômica.
 [*][b]Log:[/b] Registro global no jogo para gravar ações de mods com o país do ator, texto da ação e argumentos opcionais.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Um conjunto complementar de ferramentas de desenvolvimento, como um modelo de mod, uploader para o workshop e tradutor de mods.
[/list]
