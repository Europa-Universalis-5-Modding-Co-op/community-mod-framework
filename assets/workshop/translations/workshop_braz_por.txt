Framework de Mods da Comunidade - 1.3 Pavia / Community Mod Framework - 1.3 Pavia
===WORKSHOP_DESCRIPTION===
[i]You are on the DeepL-Generated Portuguese (Brazil) Page. [url=https://steamcommunity.com/sharedfiles/filedetails/?id=$item-id$&l=english]Click here for the Native English Page.[/url][/i]

O [b]Community Mod Framework (CMF)[/b] é um mod utilitário que visa melhorar a interoperabilidade entre mods, fornecendo aos modders ferramentas para a criação de novos recursos.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]O CMF deve ser carregado primeiro em sua ordem de carregamento de mods.[/b]

Qualquer dúvida, sinta-se à vontade para entrar em contato no Discord do EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Recursos[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]Community Mod Menu (CMM):[/url][/b] Um menu de mods compartilhado dentro do jogo. Autores de mods registram configurações dinamicamente por meio de uma API simples.
  [list]
   [*]Configurações de alternância (toggle), botão, numérico, controle deslizante (clique duplo para arrastar), menu suspenso (dropdown), texto (apenas singleplayer) e lista.
   [*]Abas por mod, grupos e busca.
   [*]Configurações globais com edição restrita ao host no modo multijogador.
   [*]Restaurar Padrões (para todos os mods ou apenas para o mod selecionado).
   [*]Janela arrastável.
   [*]Pode ser aberto pelo menu de pausa (escape) no jogo ou via atalho de teclado ('m' por padrão, pode ser remapeado).
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: ferramenta baseada em navegador para criar seu menu de mod.
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]Custom Alerts:[/url][/b] Crie e exiba alertas personalizados na barra de alertas por meio de chaves de localização.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]Action Bar:[/url][/b] Adicione botões personalizados na barra de ações com chaves de localização.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Banners]Mod Banners:[/url][/b] Exiba seu mod como um banner na tela do lobby pré-jogo, com ícone, nome e descrição. Ative via cmf_register_lobby_banner.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]Country Transfer:[/url][/b] As configurações do CMM são transferidas automaticamente ao trocar de país (trocas de tag, herança, etc.).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]Gatilho is_host:[/url][/b] Verifica se o país atual é controlado pelo jogador host.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]Alternador de Ferramentas Irrestritas:[/url][/b] Restringe recursos avançados sob uma configuração de "Ativar Ferramentas Irrestritas" (gatilho cmf_can_use_unrestricted_tools, flag cmm_set_requires_unrestricted_tools_enabled por configuração). Disponível apenas para o host no multijogador.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]Detecção de Mods:[/url][/b] Verifica se outro mod está ativo com o gatilho cmf_is_mod_active.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]Efeito cmf_suppress:[/url][/b] Suprime avisos da engine como "used but never set" e "set but never used" com uma única chamada de efeito.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]Macros de GUI:[/url][/b] Macros de operadores lógicos Nand, Nor e Xor.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]Ganchos On-Action:[/url][/b] Ganchos para início de jogo pós-lobby e carregamento de save (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) com variantes para o país do jogador. Também inclui pulsos compartilhados anuais e mensais para jogadores humanos.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/cmf_change_variable_map-Effect]Utilitários de Variable Map:[/url][/b] Auxiliares para mutação segura de mapas de variáveis (cmf_change_variable_map e variantes locais/globais).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]Mod Action Log:[/url][/b] Log global dentro do jogo para registrar ações de mods (ex: ações de ferramentas do host no multijogador, já que o log não pode ser limpo no modo MP).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Um conjunto complementar de ferramentas de desenvolvimento, como um modelo de mod, uploader para o workshop e tradutor de mods.
[/list]
