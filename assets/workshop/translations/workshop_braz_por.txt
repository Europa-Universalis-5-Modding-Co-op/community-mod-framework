[h1]Community Mod Framework[/h1]

O [b]Community Mod Framework (CMF)[/b] é um mod utilitário compartilhado que fornece um menu de mods e ferramentas de modding para o Europa Universalis V.

[b]O CMF deve ser carregado primeiro na sua ordem de carregamento de mods.[/b]

[h1]Recursos[/h1]
[list]
[*][b]Community Mod Menu (CMM):[/b] Uma janela compartilhada de configurações de mod dentro do jogo. Autores de mods registram configurações dinamicamente através de uma API simples — sem a necessidade de construir uma interface de usuário de configurações personalizada.
  [list]
   [*]Configurações de alternância (toggle), botão, numérico, controle deslizante (clique duplo para arrastar), menu suspenso (dropdown), texto (apenas para um jogador) e listas
   [*]Abas por mod, grupos e busca
   [*]Configurações globais com edição restrita ao anfitrião (host) no multijogador
   [*]Restaurar Padrões
   [*]Ferramenta CMM Visual Editor para configuração sem necessidade de código
  [/list]
[*][b]Alertas Personalizados:[/b] Crie e exiba alertas personalizados na barra de alertas através de chaves de localização.
[*][b]Barra de Ações:[/b] Adicione botões personalizados à barra de ações com chaves de localização.
[*][b]Gatilho is_host:[/b] Verifica se o país atual é controlado pelo jogador anfitrião (host).
[*][b]Efeito cmf_suppress:[/b] Suprime avisos da engine de "usado mas nunca definido" e "definido mas nunca usado" com uma única chamada de efeito.
[*][b]Hook de País de Jogador:[/b] on_actions compartilhados (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse) que são acionados para o país de cada jogador humano em pulsos anuais e mensais (ligeiramente mais eficiente do que cada mod verificar os jogadores individualmente).
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Um conjunto de ferramentas de desenvolvimento complementares, como um modelo (template) de mod, uploader para a workshop e tradutor de mods.
[/list]
