커뮤니티 모드 프레임워크 - 1.4 리오 살라도 / Community Mod Framework - 1.4 Río Salado

[b]Community Mod Framework (CMF)[/b]는 모더에게 새로운 기능을 개발할 수 있는 도구를 제공하는 동시에 모드 간의 상호 운용성을 향상시키는 것을 목표로 하는 유틸리티 모드입니다.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF는 모드 불러오기 순서(Load Order)에서 가장 먼저 배치되어야 합니다.[/b]

질문이 있으시면 EU5 Mod Coop Discord를 통해 언제든지 문의해 주세요: https://discord.gg/aqAAcCZsY7

[h1]기능[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]Community Mod Menu (CMM):[/url][/b] 공유 게임 내 모드 메뉴입니다. 모드 제작자는 간단한 API를 통해 설정을 동적으로 등록할 수 있습니다.
  [list]
   [*]토글, 버튼, 숫자, 슬라이더(두 번 클릭하여 드래그), 드롭다운, 텍스트(싱글 플레이어 전용), 리스트 설정 지원
   [*]모드별 탭, 하위 탭, 그룹 및 검색 기능
   [*]접이식 설정 그룹
   [*]전역 설정 및 호스트 전용 멀티플레이어 편집 기능
   [*]기본값으로 재설정 (모든 모드 또는 선택한 모드만)
   [*]드래그 가능한 창
   [*]게임 내 ESC 메뉴 또는 단축키(기본값 'm', 변경 가능)로 열기 가능
   [*]국가가 선택되지 않은 상태, 국가 선택 로비, 관전자 모드에서도 열리며 마지막 국가의 설정값을 표시합니다. (단, 국가를 선택하기 전까지 설정 변경은 불가능합니다.)
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: 브라우저 기반의 모드 메뉴 제작 도구
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]맞춤형 알림 (Custom Alerts):[/url][/b] 로컬라이제이션 키를 통해 알림 표시줄에 맞춤형 알림을 생성하고 표시합니다. 구성 가능한 좌클릭 액션과 바닐라 방식의 숨기기 및 음소거 기능을 지원합니다.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]액션 바 (Action Bar):[/url][/b] 로컬라이제이션 키를 사용하여 맞춤형 액션 바 버튼을 추가합니다.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Banners]모드 배너 (Mod Banners):[/url][/b] 게임 시작 전 로비 화면에 모드의 아이콘, 이름, 설명을 배너로 표시합니다. cmf_register_lobby_banner를 통해 활성화할 수 있습니다.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]국가 이전 (Country Transfer):[/url][/b] 국가 전환(태그 변경, 상속 등) 시 CMM 설정이 자동으로 이전됩니다.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]is_host 트리거:[/url][/b] 현재 국가가 호스트 플레이어에 의해 제어되고 있는지 확인합니다.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]제한 없는 도구 토글 (Unrestricted Tools Toggle):[/url][/b] "제한 없는 도구 활성화" 설정을 통해 제한된 기능에 대한 접근을 제어합니다. (cmf_can_use_unrestricted_tools 트리거, 설정당 cmm_set_requires_unrestricted_tools_enabled 플래그 사용) 멀티플레이어에서는 호스트만 사용할 수 있습니다.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]모드 감지 (Mod Detection):[/url][/b] cmf_is_mod_active 트리거로 다른 모드의 활성화 여부를 확인하거나, cmf_was_mod_active_at_game_start로 게임 시작 시 활성화 여부를 확인합니다.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]cmf_suppress 효과:[/url][/b] 단 한 번의 효과 호출로 "used but never set" 및 "set but never used" 엔진 경고를 억제합니다.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]GUI 매크로:[/url][/b] Nand, Nor, Xor 논리 연산자 매크로를 제공합니다.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Improved-Vanilla-Top-Level-Widget-Overrides]개선된 바닐라 최상위 위젯 오버라이드:[/url][/b] 파일 내의 모든 타입과 템플릿을 복사할 필요 없이 최상위 바닐라 위젯(lateralviews, topbar, outliner entries 등)을 오버라이드합니다. CMF에 추출된 정의가 포함되어 있어 오버라이드할 위젯 자체만 있으면 됩니다.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]온-액션 훅 (On-Action Hooks):[/url][/b] 세이브 불러오기 훅(on_game_load, on_game_load_after_lobby)과 게임 시작 및 세이브 불러오기에 대한 플레이어 국가 변형을 지원합니다. 또한 플레이어를 위한 공유 연간 및 월간 펄스(pulse)를 포함합니다.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]모드 액션 로그 (Mod Action Log):[/url][/b] 모드 작업을 기록하는 전역 게임 내 로그입니다. (예: 멀티플레이어에서 로그 삭제가 불가능하므로 호스트 도구 사용 기록 등에 유용)
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] 모드 템플릿, 창작마당 업로더, 모드 번역기 등 개발 도구 모음입니다.
[/list]
