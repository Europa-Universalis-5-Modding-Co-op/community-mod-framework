[h1]Community Mod Framework[/h1]

El [b]Community Mod Framework (CMF)[/b] es un mod de utilidad compartida que proporciona un menú de mods y herramientas de modding para Europa Universalis V.

[b]CMF debe cargarse primero en tu orden de carga de mods.[/b]

[h1]Características[/h1]
[list]
[*][b]Community Mod Menu (CMM):[/b] Una ventana compartida de ajustes de mods dentro del juego. Los autores de mods registran sus ajustes dinámicamente a través de una API sencilla, sin necesidad de construir una interfaz de usuario personalizada.
  [list]
   [*]Ajustes de interruptor, botón, numéricos, deslizador (doble clic para arrastrar), desplegable, texto (solo para un jugador) y lista.
   [*]Pestañas por mod, grupos y búsqueda.
   [*]Ajustes globales con edición exclusiva para el anfitrión en multijugador.
   [*]Restablecer a valores predeterminados.
   [*]Herramienta CMM Visual Editor para una configuración sin necesidad de código.
  [/list]
[*][b]Alertas personalizadas:[/b] Crea y muestra alertas personalizadas en la barra de alertas mediante claves de localización.
[*][b]Barra de acciones:[/b] Añade botones personalizados a la barra de acciones con claves de localización.
[*][b]Activador (Trigger) is_host:[/b] Comprueba si el país actual está controlado por el jugador anfitrión.
[*][b]Efecto cmf_suppress:[/b] Suprime las advertencias del motor "used but never set" y "set but never used" con una sola llamada al efecto.
[*][b]Gancho (Hook) de país de jugador:[/b] on_actions compartidos (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse) que se activan para el país de cada jugador humano en pulsos anuales y mensuales (ligeramente más eficiente que si cada mod comprobara los jugadores individualmente).
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Un conjunto complementario de herramientas de desarrollo, como una plantilla de mod, cargador de workshop y traductor de mods.
[/list]
