[h1]Community Mod Framework[/h1]

El [b]Community Mod Framework (CMF)[/b] es un mod de utilidad compartido que proporciona un menú de configuración y herramientas de creación de mods para Europa Universalis V.

[b]CMF debe cargarse primero en el orden de carga de tus mods.[/b]

[h1]Características[/h1]
[list]
[*][b]Community Mod Menu (CMM):[/b] Una ventana de ajustes de mods compartida dentro del juego. Los autores de mods registran sus ajustes de forma dinámica a través de una API sencilla, sin necesidad de crear una interfaz de usuario personalizada.
  [list]
   [*]Ajustes de interruptor, botón, numéricos, deslizadores (doble clic para arrastrar), desplegables, de texto (solo para un jugador) y de lista.
   [*]Pestañas por mod, grupos y búsqueda.
   [*]Ajustes globales con edición exclusiva para el anfitrión en multijugador.
   [*]Restablecer valores predeterminados.
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url] — herramienta basada en el navegador para crear ajustes sin necesidad de programar.
  [/list]
[*][b]Alertas personalizadas:[/b] Crea y muestra alertas personalizadas en la barra de alertas mediante claves de localización.
[*][b]Barra de acciones:[/b] Añade botones personalizados a la barra de acciones con claves de localización.
[*][b]Disparador is_host:[/b] Comprueba si el país actual está controlado por el jugador anfitrión.
[*][b]Efecto cmf_suppress:[/b] Suprime las advertencias del motor "used but never set" y "set but never used" con una sola llamada de efecto.
[*][b]Gancho de país de jugador:[/b] Acciones compartidas (on_actions: cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse) que se activan para el país de cada jugador humano en pulsos anuales y mensuales (ligeramente más eficiente que si cada mod comprobara los jugadores de forma individual).
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Un conjunto complementario de herramientas de desarrollo, como una plantilla de mod, un cargador para la workshop y un traductor de mods.
[/list]
