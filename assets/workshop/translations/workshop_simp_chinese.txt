社区模组框架 - 1.3 帕维亚 / Community Mod Framework - 1.3 Pavia
===WORKSHOP_DESCRIPTION===

[b]社区模组框架 (CMF)[/b] 是一款旨在提高模组间互操作性，同时为模组制作者提供创建新功能工具的实用型模组。

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF 应当位于您模组加载顺序的首位。[/b]

如有任何疑问，欢迎访问 EU5 Mod Coop Discord 联系我们：https://discord.gg/aqAAcCZsY7

[h1]功能特点[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]社区模组菜单 (CMM):[/url][/b] 一个共享的游戏内模组菜单。模组作者可通过简单的 API 动态注册设置。
  [list]
   [*]支持开关、按钮、数值、滑块（双击后拖动）、下拉菜单、文本（仅限单人模式）以及列表设置
   [*]支持针对每个模组的分页、分组和搜索功能
   [*]全局设置，在多人模式下仅限主机编辑
   [*]重置为默认设置（全部模组，或仅针对所选模组）
   [*]可拖动窗口
   [*]可从游戏内的退出菜单 (Esc) 打开，或通过快捷键打开（默认 'm' 键，可重新绑定）。
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM 可视化编辑器[/url]：用于创建您的模组菜单的浏览器端工具。
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]自定义警报:[/url][/b] 通过本地化键在警报栏创建并显示自定义警报。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]动作栏:[/url][/b] 使用本地化键添加自定义动作栏按钮。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Banners]模组横幅:[/url][/b] 在游戏前大厅界面显示您的模组横幅，包含图标、名称和描述。通过 cmf_register_lobby_banner 加入。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]国家转移:[/url][/b] 切换国家（切换 Tag、继承等）时，CMM 设置会自动转移。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]is_host 触发器:[/url][/b] 检查当前国家是否由主机玩家控制。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]无限制工具开关:[/url][/b] 通过“启用无限制工具”设置来管控受限功能（cmf_can_use_unrestricted_tools 触发器，cmm_set_requires_unrestricted_tools_enabled 每项设置标记）。在多人模式下仅主机可用。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]模组检测:[/url][/b] 使用 cmf_is_mod_active 触发器检查其他模组是否已启用。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]cmf_suppress 效果:[/url][/b] 通过单次效果调用屏蔽“已使用但未设置 (used but never set)”和“已设置但未有效 (set but never used)”的引擎警告。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]GUI 宏:[/url][/b] Nand、Nor 和 Xor 逻辑运算符宏。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]动作钩子 (On-Action Hooks):[/url][/b] 大厅后的游戏启动及存档加载钩子（on_game_start_after_lobby、on_game_load、on_game_load_after_lobby），包含玩家国家变体。还包括面向人类玩家的共享年度和月度脉冲 (Pulses)。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/cmf_change_variable_map-Effect]变量映射 (Variable Map) 实用程序:[/url][/b] 安全的变量映射更改助手（cmf_change_variable_map 及其本地/全局变体）。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]模组动作日志:[/url][/b] 记录模组动作的全局游戏内日志（例如多人模式中的主机工具动作，因为日志在多人模式中无法被清除）。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]社区模组工具包 (CMT):[/url][/b] 一套配套的开发工具，包含模组模板、工坊上传器和模组翻译器。
[/list]
