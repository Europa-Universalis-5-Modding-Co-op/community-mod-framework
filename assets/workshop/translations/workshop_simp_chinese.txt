社区模组框架 - 1.3 帕维亚 / Community Mod Framework - 1.3 Pavia

[b]社区模组框架 (Community Mod Framework, CMF)[/b] 是一个功能性模组，旨在提高模组间的互操作性，同时为模组作者提供创建新功能的工具。

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF 应该在您的模组加载顺序中排在首位。[/b]

如有任何疑问，请随时在 EU5 Mod Coop Discord 上联系：https://discord.gg/aqAAcCZsY7

[h1]功能[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]社区模组菜单 (Community Mod Menu, CMM)：[/url][/b] 一个共享的游戏内模组菜单。模组作者可以通过简单的 API 动态注册设置。
  [list]
   [*]开关、按钮、数值、滑块（双击拖动）、下拉菜单、文本（仅限单人模式）以及列表设置
   [*]针对每个模组的选项卡、分组和搜索功能
   [*]全局设置，多人模式下仅限房主编辑
   [*]重置为默认值（所有模组或仅选定的模组）
   [*]可拖动的窗口
   [*]可以从游戏内的 Esc 菜单打开，或通过快捷键（默认为 'm'，可重新绑定）打开。
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM 可视化编辑器[/url]：用于创建模组菜单的基于浏览器的工具
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]自定义警告：[/url][/b] 通过本地化键值在警告栏中创建并显示自定义警告。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]动作栏：[/url][/b] 通过本地化键值添加自定义动作栏按钮。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Banners]模组横幅：[/url][/b] 在游戏前的大厅界面中以横幅形式显示您的模组，包括图标、名称和描述。使用 cmf_register_lobby_banner 启用。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]国家转移：[/url][/b] 在切换国家（切换 Tag、继承等）时，CMM 设置会自动转移。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]is_host 触发器：[/url][/b] 检查当前国家是否由房主玩家控制。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]无限制工具开关：[/url][/b] 将受限功能置于“启用无限制工具”设置之后（使用 cmf_can_use_unrestricted_tools 触发器，以及每个设置项的 cmm_set_requires_unrestricted_tools_enabled 标志）。多人模式下仅房主可用。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]模组检测：[/url][/b] 使用 cmf_is_mod_active 触发器检查另一个模组是否处于激活状态。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]cmf_suppress 效果：[/url][/b] 通过单次效果调用屏蔽引擎关于“已使用但未设置”和“已设置但未使用”的警告。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]GUI 宏：[/url][/b] Nand、Nor 和 Xor 逻辑运算符宏。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Improved-Vanilla-Top-Level-Widget-Overrides]改进的原版顶级组件重写：[/url][/b] 重写原版顶级组件（侧边视图、顶栏、大纲条目等），无需从文件中复制每个类型和模板。CMF 包含提取出的定义，因此您的重写只需包含组件本身。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]On-Action 挂钩：[/url][/b] 大厅后的游戏开始和存档加载挂钩（on_game_start_after_lobby、on_game_load、on_game_load_after_lobby），包含玩家国家变体。还包括针对人类玩家的共享年度和月度脉冲（Pulse）。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/cmf_change_variable_map-Effect]变量映射工具：[/url][/b] 安全的变量映射更改辅助工具（cmf_change_variable_map 及其本地/全局变体）。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]模组动作日志：[/url][/b] 用于记录模组动作的全游戏日志（例如多人模式下的房主工具操作，因为多人模式下的日志无法清除）。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]社区模组工具集 (Community Mod Toolkit, CMT)：[/url][/b] 一套配套的开发工具，如模组模板、创意工坊上传器和模组翻译器。
[/list]
