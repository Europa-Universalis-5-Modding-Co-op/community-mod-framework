社区模组框架与菜单 / Community Mod Framework - 1.3 Pavia
===WORKSHOP_DESCRIPTION===

[b]Community Mod Framework (CMF)[/b] 是一个工具类模组，旨在提高模组间的兼容性，并为模组作者提供创建新功能的工具。

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF 应放在您模组加载顺序的首位。[/b]

如有任何疑问，请随时通过 EU5 Mod Coop Discord 联系：https://discord.gg/aqAAcCZsY7

[h1]功能[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]社区模组菜单 (CMM)：[/url][/b] 一个共享的游戏内模组菜单。模组作者可以通过简单的 API 动态注册设置，无需构建自定义设置界面。
  [list]
   [*]开关、按钮、数值、滑块（双击可拖动）、下拉菜单、文本（仅限单人模式）和列表设置
   [*]支持各个模组独立的标签页、分组和搜索功能
   [*]全局设置，在多人模式下仅限房主编辑
   [*]重置为默认值
   [*]可拖动窗口
   [*]可以从游戏内的退出菜单（Esc 菜单）中打开，或通过快捷键打开（默认为“m”，可重新绑定）。
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM 可视化编辑器[/url]：用于创建模组菜单的浏览器端工具
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]自定义提醒：[/url][/b] 通过本地化键位在提醒栏中创建并显示自定义提醒。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]动作栏：[/url][/b] 使用本地化键位添加自定义动作栏按钮。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]国家转移：[/url][/b] 切换国家（Tag 切换、继承等）时，CMM 设置会自动转移。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]is_host 触发器：[/url][/b] 检查当前国家是否由房主玩家控制。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]不受限工具开关：[/url][/b] 通过“开启不受限工具”设置（cmf_can_use_unrestricted_tools 触发器，cmm_set_requires_unrestricted_tools_enabled 单项设置标记）来限制特定功能。在多人模式下仅房主可用。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]模组检测：[/url][/b] 使用 cmf_is_mod_active 触发器检查另一个模组是否处于激活状态。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]cmf_suppress 效果：[/url][/b] 通过单次效果调用来抑制引擎中“已使用但从未设置”和“已设置但从未使用”的警告。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]GUI 宏：[/url][/b] Nand、Nor 和 Xor 逻辑运算符宏。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]On-Action 钩子：[/url][/b] 大厅后游戏开始和存档加载钩子（on_game_start_after_lobby、on_game_load、on_game_load_after_lobby）以及玩家国家变体。还包括针对人类玩家的共享年度和月度脉冲（Pulses）。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/cmf_change_variable_map-Effect]变量映射工具：[/url][/b] 安全的变量映射（Variable Map）更改辅助工具（cmf_change_variable_map 及其本地/全局变体），可原子化地处理“先删除后添加”操作。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]模组动作日志：[/url][/b] 全局游戏内日志，用于记录模组动作（例如多人模式下的房主工具动作，因为该日志在多人模式下无法清除）。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]社区模组工具箱 (CMT)：[/url][/b] 一套配套的开发工具，例如模组模板、创意工坊上传器和模组翻译器。
[/list]
