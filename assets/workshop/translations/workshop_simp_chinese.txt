社区模组框架 - 1.3 帕维亚 / Community Mod Framework - 1.3 Pavia
===WORKSHOP_DESCRIPTION===

[b]社区模组框架 (CMF)[/b] 是一个工具类模组，旨在提高模组间的互操作性，同时为模组作者提供创建新功能的工具。

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF 应当在您的模组加载顺序中排在首位。[/b]

如有任何疑问，欢迎在 EU5 模组协作 Discord 频道联系我们：https://discord.gg/aqAAcCZsY7

[h1]功能[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]社区模组菜单 (CMM):[/url][/b] 一个共享的游戏内模组菜单。模组作者可以通过简单的 API 动态注册设置。
  [list]
   [*]切换开关、按钮、数值、滑块（双击拖动）、下拉列表、文本（仅限单人模式）及列表设置
   [*]按模组划分的标签页、子标签页、分组及搜索功能
   [*]可折叠设置组
   [*]全局设置，多人模式下仅限房主编辑
   [*]恢复默认设置（所有模组或仅限选定模组）
   [*]可拖动窗口
   [*]可以从游戏内的 Esc 菜单中打开。或者通过按键绑定（默认为 'm'，可更改）。
   [*]打开时若未选择国家，在国家选择大厅和观察者模式下，将显示您上一个国家的数值。在选择国家之前无法更改设置。
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM 可视化编辑器[/url]：基于浏览器的模组菜单创建工具
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]自定义警报：[/url][/b] 通过本地化键值在警报栏创建并显示自定义警报，具有可配置的左键点击动作，以及原版风格的隐藏和静音功能。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]动作条：[/url][/b] 使用本地化键值添加自定义动作条按钮。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Banners]模组横幅：[/url][/b] 在游戏开始前的大厅界面上以横幅形式展示您的模组，包含图标、名称和描述。通过 cmf_register_lobby_banner 加入。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]国家转移：[/url][/b] 在切换国家（切换国家、继承等）时，CMM 设置会自动转移。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]is_host 触发器：[/url][/b] 检查当前国家是否由房主玩家控制。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]无限制工具切换：[/url][/b] 通过“启用无限制工具”设置来限制特定功能（cmf_can_use_unrestricted_tools 触发器，每个设置的 cmm_set_requires_unrestricted_tools_enabled 标志）。多人模式下仅房主可用。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]模组检测：[/url][/b] 使用 cmf_is_mod_active 触发器检查另一个模组是否处于激活状态，或使用 cmf_was_mod_active_at_game_start 检查游戏启动时该模组是否处于激活状态。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]cmf_suppress 效果：[/url][/b] 通过单次效果调用即可抑制引擎产生的“已使用但从未设置”以及“已设置但从未使用”的警告。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]GUI 宏：[/url][/b] 与非 (Nand)、或非 (Nor) 以及异或 (Xor) 逻辑运算符宏。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Improved-Vanilla-Top-Level-Widget-Overrides]改进的原版顶层组件 (Widget) 覆盖：[/url][/b] 覆盖原版顶层组件（侧视图、顶栏、大纲条目等）而无需复制其文件中的每个类型和模板。CMF 包含了提取好的定义，因此您的覆盖仅需要组件本身即可。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]On-Action 钩子：[/url][/b] 包含大厅后游戏开始和存档加载钩子（on_game_start_after_lobby, on_game_load, on_game_load_after_lobby）及其玩家国家变体。还包括面向玩家的共享年度和月度脉冲。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]模组动作日志：[/url][/b] 用于记录模组动作的全局游戏内日志（例如多人模式下的房主工具动作，因为多人模式下日志无法被清除）。
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]社区模组工具集 (CMT):[/url][/b] 一套配套的开发工具，例如模组模板、创意工坊上传器和模组翻译器。
[/list]
