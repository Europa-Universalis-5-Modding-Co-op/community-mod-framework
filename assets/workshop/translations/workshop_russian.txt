[b]Community Mod Framework (CMF)[/b] — это служебная модификация, цель которой — улучшить совместимость модов и предоставить разработчикам инструменты для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/banner.png[/img]

[b]CMF должен загружаться первым в вашем списке модов.[/b]

Если у вас есть вопросы, обращайтесь в Discord-сообщество EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b]Community Mod Menu (CMM):[/b] Общее внутриигровое меню модов. Авторы модов регистрируют настройки динамически через простой API — нет необходимости создавать собственный интерфейс настроек.
  [list]
   [*]Переключатели, кнопки, числовые поля, ползунки (двойной клик для перетаскивания), выпадающие списки, текстовые поля (только для одиночной игры) и списки настроек
   [*]Вкладки для каждого мода, группы и поиск
   [*]Глобальные настройки с возможностью редактирования в мультиплеере только для хоста
   [*]Сброс до настроек по умолчанию
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url] — браузерный инструмент для создания меню вашего мода
  [/list]
 [*][b]Пользовательские оповещения:[/b] Создавайте и отображайте собственные оповещения в панели уведомлений с помощью ключей локализации.
 [*][b]Панель действий:[/b] Добавляйте собственные кнопки на панель действий с помощью ключей локализации.
 [*][b]Триггер is_host:[/b] Проверка, контролируется ли текущая страна игроком-хостом.
 [*][b]Эффект cmf_suppress:[/b] Подавляет предупреждения движка "used but never set" и "set but never used" одним вызовом эффекта.
 [*][b]On-Action Hooks (хуки):[/b] Хуки старта игры после лобби и загрузки сохранений (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) с вариантами для страны игрока. Также включает общие ежегодные и ежемесячные импульсы для игроков-людей.
 [*][b]Утилиты карт переменных:[/b] Безопасные помощники для изменения карт переменных (cmf_change_variable_map и локальные/глобальные варианты), которые выполняют удаление и последующее добавление атомарно.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Набор инструментов для разработки, включающий шаблон мода, загрузчик в Workshop и переводчик модов.
[/list]
