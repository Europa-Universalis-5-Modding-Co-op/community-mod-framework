Фреймворк сообщества для модов — 1.3 Павия / Community Mod Framework - 1.3 Pavia
===WORKSHOP_DESCRIPTION===

[b]Community Mod Framework (CMF)[/b] — это вспомогательная модификация, целью которой является улучшение совместимости модов и предоставление моддерам инструментов для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF должен быть первым в вашем порядке загрузки модов.[/b]

По любым вопросам обращайтесь в Discord-сообщество EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]Community Mod Menu (CMM):[/url][/b] Общее внутриигровое меню модов. Авторы модов динамически регистрируют настройки через простой API.
  [list]
   [*]Переключатели, кнопки, числовые значения, ползунки (двойной клик для перетаскивания), выпадающие списки, текст (только для одиночной игры) и настройки списков.
   [*]Вкладки для отдельных модов, подвкладки, группы и поиск.
   [*]Сворачиваемые группы настроек.
   [*]Глобальные настройки с возможностью редактирования только хостом в мультиплеере.
   [*]Сброс к значениям по умолчанию (для всех модов или только для выбранного).
   [*]Перемещаемое окно.
   [*]Можно открыть из меню паузы (Esc) в игре или с помощью горячей клавиши (по умолчанию «m», можно переназначить).
   [*]Открывается без выбранной страны в лобби выбора стран и в режиме наблюдателя, показывая значения вашей последней страны. Настройки нельзя изменить, пока вы не выберете страну.
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: браузерный инструмент для создания вашего меню мода.
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]Custom Alerts:[/url][/b] Создавайте и отображайте настраиваемые оповещения в панели уведомлений с помощью ключей локализации, с настраиваемыми действиями по щелчку левой кнопкой мыши и функциями скрытия/отключения звука в стиле ванильной игры.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]Action Bar:[/url][/b] Добавляйте настраиваемые кнопки на панель действий с помощью ключей локализации.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Banners]Mod Banners:[/url][/b] Отобразите свой мод в виде баннера на экране лобби перед игрой с иконкой, названием и описанием. Подключается через cmf_register_lobby_banner.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]Country Transfer:[/url][/b] Настройки CMM автоматически переносятся при смене страны (смена тега, наследование и т. д.).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]is_host Trigger:[/url][/b] Проверка, управляется ли текущая страна игроком-хостом.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]Unrestricted Tools Toggle:[/url][/b] Ограничивайте доступ к функциям с помощью настройки «Enable Unrestricted Tools» (триггер cmf_can_use_unrestricted_tools, флаг настройки cmm_set_requires_unrestricted_tools_enabled). Доступно только хосту в мультиплеере.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]Mod Detection:[/url][/b] Проверяйте, активен ли другой мод с помощью триггера cmf_is_mod_active, или был ли он активен при запуске игры с помощью cmf_was_mod_active_at_game_start.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]cmf_suppress Effect:[/url][/b] Подавляйте предупреждения движка «used but never set» и «set but never used» одним вызовом эффекта.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]GUI Macros:[/url][/b] Макросы логических операторов Nand, Nor и Xor.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Improved-Vanilla-Top-Level-Widget-Overrides]Improved Vanilla Top-Level Widget Overrides:[/url][/b] Переопределяйте ванильные виджеты верхнего уровня (боковые панели, верхнюю панель, записи планировщика и др.) без копирования каждого типа и шаблона из исходного файла. CMF содержит извлеченные определения, поэтому вашему переопределению нужен только сам виджет.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]On-Action Hooks:[/url][/b] Хуки на запуск игры после лобби и загрузку сохранения (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) с вариантами для страны игрока. Также включает общие ежегодные и ежемесячные импульсы для игроков-людей.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]Mod Action Log:[/url][/b] Глобальный внутриигровой журнал для записи действий мода (например, действий инструментов хоста в мультиплеере, так как журнал невозможно очистить в МП).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Набор инструментов для разработки, таких как шаблон мода, загрузчик в Workshop и переводчик модов.
[/list]
