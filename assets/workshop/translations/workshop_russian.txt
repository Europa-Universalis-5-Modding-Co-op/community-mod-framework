[b]Community Mod Framework (CMF)[/b] — это служебный мод, целью которого является улучшение совместимости модов и предоставление инструментов для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/banner.png[/img]

[b]CMF должен загружаться первым в вашем порядке загрузки модов.[/b]

Если у вас есть вопросы, обращайтесь в EU5 Mod Coop Discord: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b]Community Mod Menu (CMM):[/b] Общее игровое меню модов. Авторы модов динамически регистрируют настройки через простой API — нет необходимости создавать собственный интерфейс настроек.
  [list]
   [*]Переключатели, кнопки, числовые значения, ползунки (двойной клик для перетаскивания), выпадающие списки, текст (только для одиночной игры) и списки настроек.
   [*]Вкладки для каждого мода, группы и поиск.
   [*]Глобальные настройки с возможностью редактирования только хостом в многопользовательской игре.
   [*]Сброс к настройкам по умолчанию.
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url] — браузерный инструмент для создания меню вашего мода.
  [/list]
 [*][b]Пользовательские оповещения:[/b] Создавайте и отображайте собственные оповещения в панели оповещений с помощью ключей локализации.
 [*][b]Панель действий (Action Bar):[/b] Добавляйте кастомные кнопки на панель действий через ключи локализации.
 [*][b]Триггер is_host:[/b] Проверка, контролируется ли текущая страна игроком-хостом.
 [*][b]Эффект cmf_suppress:[/b] Подавление предупреждений движка "used but never set" и "set but never used" одним вызовом эффекта.
 [*][b]On-Action хуки:[/b] Хуки для старта игры после лобби и загрузки сохранений (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) с вариантами для страны игрока. Также включает общие ежегодные и ежемесячные пульсы для игроков-людей.
 [*][b]Окно проверки зависимостей:[/b] Готовое всплывающее окно в главном меню, которое предупреждает игроков об отсутствии CMF, с опциями автоматического включения и подписки в Workshop.
 [*][b]Утилиты Variable Map:[/b] Помощники для безопасного изменения карт переменных (cmf_change_variable_map и локальные/глобальные варианты), которые атомарно обрабатывают удаление и последующее добавление.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Сопутствующий набор инструментов для разработки, таких как шаблон мода, загрузчик в мастерскую и переводчик модов.
[/list]
