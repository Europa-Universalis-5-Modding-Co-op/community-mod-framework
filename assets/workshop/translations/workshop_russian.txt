[h1]Community Mod Framework[/h1]

[b]Community Mod Framework (CMF)[/b] — это общий вспомогательный мод, который предоставляет меню модов и инструменты для моддинга Europa Universalis V.

[b]CMF должен быть первым в вашем списке загрузки модов.[/b]

[h1]Особенности[/h1]
[list]
[*][b]Community Mod Menu (CMM):[/b] Общее внутриигровое окно настроек модов. Авторы модов регистрируют настройки динамически через простой API — нет необходимости создавать собственный интерфейс настроек.
  [list]
   [*]Переключатели, кнопки, числовые значения, ползунки (двойной клик для перетаскивания), выпадающие списки, текст (только для одиночной игры) и настройки списков
   [*]Вкладки, группы и поиск для каждого мода
   [*]Глобальные настройки с возможностью редактирования только хостом в мультиплеере
   [*]Сброс к настройкам по умолчанию
   [*]Инструмент CMM Visual Editor для настройки без написания кода
  [/list]
[*][b]Пользовательские оповещения:[/b] Создавайте и отображайте собственные оповещения на панели уведомлений с помощью ключей локализации.
[*][b]Панель действий:[/b] Добавляйте собственные кнопки на панель действий с помощью ключей локализации.
[*][b]Триггер is_host:[/b] Проверяет, контролируется ли текущая страна хостом.
[*][b]Эффект cmf_suppress:[/b] Позволяет подавить предупреждения движка «used but never set» и «set but never used» одним вызовом эффекта.
[*][b]Хук страны игрока:[/b] Общие on_actions (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse), которые срабатывают для страны каждого игрока-человека в ежегодных и ежемесячных циклах (чуть более эффективно, чем если бы каждый мод проверял наличие игроков по отдельности).
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Набор сопутствующих инструментов разработки, таких как шаблон мода, загрузчик в Workshop и переводчик модов.
[/list]
