[b]Community Mod Framework (CMF)[/b] — это служебная модификация, целью которой является улучшение совместимости модов и предоставление моддерам инструментов для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/banner.png[/img]

[b]CMF должен быть первым в вашем списке загрузки модов.[/b]

Если у вас есть вопросы, обращайтесь в EU5 Mod Coop Discord: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b]Community Mod Menu (CMM):[/b] общее внутриигровое меню модов. Авторы модов динамически регистрируют настройки через простой API — нет необходимости создавать собственный интерфейс настроек.
  [list]
   [*]Переключатели, кнопки, числовые значения, слайдеры (двойной клик для перетаскивания), выпадающие списки, текстовые поля (только для одиночной игры) и настройки списков
   [*]Отдельные вкладки для каждого мода, группы и поиск
   [*]Глобальные настройки с возможностью редактирования только хостом в мультиплеере
   [*]Сброс к настройкам по умолчанию
   [*]Перетаскиваемое окно
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url] — браузерный инструмент для создания меню вашего мода
  [/list]
 [*][b]Пользовательские оповещения:[/b] Создавайте и показывайте собственные оповещения в панели алертов с помощью ключей локализации.
 [*][b]Панель действий:[/b] Добавляйте пользовательские кнопки на панель действий с помощью ключей локализации.
 [*][b]Перенос страны:[/b] Настройки CMM автоматически переносятся при смене страны (смена тега, наследование и т. д.).
 [*][b]Триггер is_host:[/b] Проверяет, контролируется ли текущая страна игроком-хостом.
 [*][b]Эффект cmf_suppress:[/b] Подавляйте предупреждения движка «used but never set» и «set but never used» одним вызовом эффекта.
 [*][b]On-Action Хуки:[/b] Хуки начала игры после лобби и загрузки сохранения (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) с вариантами для страны игрока. Также включает общие ежегодные и ежемесячные пульсы для игроков-людей.
 [*][b]Утилиты для карт переменных (Variable Map):[/b] Вспомогательные функции для безопасного изменения карт переменных (cmf_change_variable_map и локальные/глобальные варианты), которые выполняют удаление и последующее добавление атомарно.
 [*][b]Лог:[/b] Общий внутриигровой лог для записи действий мода с указанием страны-исполнителя, текста действия и дополнительных аргументов.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] набор вспомогательных инструментов для разработки, таких как шаблон мода, загрузчик в Workshop и переводчик модов.
[/list]
