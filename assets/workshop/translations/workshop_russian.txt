[b]Community Mod Framework (CMF)[/b] — это служебный мод, целью которого является улучшение взаимосовместимости модов и предоставление моддерам инструментов для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF должен загружаться первым в вашем списке загрузки модов.[/b]

Если у вас возникли вопросы, обращайтесь в Discord сообщества моддеров EU5: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]Community Mod Menu (CMM):[/url][/b] Общее внутриигровое меню модов. Авторы модов динамически регистрируют настройки через простой API.
  [list]
   [*]Настройки в виде переключателей, кнопок, числовых полей, ползунков (двойной клик для перетаскивания), выпадающих списков, текста (только для одиночной игры) и списков.
   [*]Отдельные вкладки для каждого мода, группы и поиск.
   [*]Глобальные настройки с возможностью редактирования только хостом в мультиплеере.
   [*]Сброс к значениям по умолчанию (для всех модов или только для выбранного).
   [*]Перетаскиваемое окно.
   [*]Меню можно открыть из меню паузы (Esc) в игре или с помощью горячей клавиши (по умолчанию 'm', можно переназначить).
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: браузерный инструмент для создания вашего меню мода.
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]Пользовательские оповещения:[/url][/b] Создавайте и отображайте собственные оповещения на панели оповещений с помощью ключей локализации.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]Панель действий:[/url][/b] Добавляйте собственные кнопки на панель действий с помощью ключей локализации.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Banners]Баннеры модов:[/url][/b] Отображение вашего мода в виде баннера на экране лобби перед игрой с иконкой, названием и описанием. Активируется через cmf_register_lobby_banner.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]Передача страны:[/url][/b] Настройки CMM автоматически переносятся при смене страны (смена тега, наследование и т. д.).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]Триггер is_host:[/url][/b] Проверка, контролируется ли текущая страна игроком-хостом.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]Переключатель неограниченных инструментов:[/url][/b] Ограничение доступа к определенным функциям через настройку «Enable Unrestricted Tools» (триггер cmf_can_use_unrestricted_tools, флаг cmm_set_requires_unrestricted_tools_enabled для отдельных настроек). Доступно только для хоста в мультиплеере.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]Обнаружение модов:[/url][/b] Проверка активности другого мода с помощью триггера cmf_is_mod_active.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]Эффект cmf_suppress:[/url][/b] Подавление предупреждений движка «used but never set» и «set but never used» одним вызовом эффекта.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]Макросы GUI:[/url][/b] Логические макросы Nand, Nor и Xor.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Improved-Vanilla-Top-Level-Widget-Overrides]Улучшенное переопределение ванильных виджетов верхнего уровня:[/url][/b] Переопределяйте ванильные виджеты верхнего уровня (lateralviews, topbar, записи планировщика и др.) без копирования каждого типа и шаблона из исходного файла. CMF содержит извлеченные определения, поэтому для переопределения нужен только сам виджет.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]Хуки On-Action:[/url][/b] Хуки начала игры после лобби и загрузки сохранений (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) с вариантами для страны игрока. Также включает общие ежегодные и ежемесячные пульсы для игроков-людей.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]Журнал действий мода:[/url][/b] Глобальный внутриигровой лог для записи действий мода (например, действия инструментов хоста в мультиплеере, так как журнал невозможно очистить в MP).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Сопутствующий набор инструментов разработки, таких как шаблон мода, загрузчик в мастерскую и переводчик модов.
[/list]
