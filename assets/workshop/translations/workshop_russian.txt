[b]Community Mod Framework (CMF)[/b] — это вспомогательный мод, предназначенный для улучшения совместимости модов между собой и предоставления моддерам инструментов для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF должен загружаться первым в вашем списке загрузки модов.[/b]

Если у вас есть вопросы, не стесняйтесь обращаться в Discord сообщества EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]Community Mod Menu (CMM):[/url][/b] Общее внутриигровое меню модов. Авторы модов регистрируют настройки динамически через простой API.
  [list]
   [*]Переключатели, кнопки, числовые значения, ползунки (двойной клик для перетаскивания), выпадающие списки, текст (только для одиночной игры) и списки настроек.
   [*]Вкладки для каждого мода, группы и поиск.
   [*]Глобальные настройки с возможностью редактирования в мультиплеере только для хоста.
   [*]Сброс к настройкам по умолчанию (для всех модов или только для выбранного).
   [*]Перетаскиваемое окно.
   [*]Можно открыть из меню паузы в игре или с помощью горячей клавиши (по умолчанию «m», можно переназначить).
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: браузерный инструмент для создания меню вашего мода.
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]Пользовательские оповещения:[/url][/b] Создавайте и отображайте собственные оповещения в панели оповещений с помощью ключей локализации.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]Панель действий:[/url][/b] Добавляйте пользовательские кнопки на панель действий с помощью ключей локализации.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Banners]Баннеры модов:[/url][/b] Отображайте ваш мод в виде баннера на экране лобби перед игрой с иконкой, названием и описанием. Подключается через cmf_register_lobby_banner.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]Перенос при смене страны:[/url][/b] Настройки CMM автоматически переносятся при смене страны (смена тега, наследование и т. д.).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]Триггер is_host:[/url][/b] Проверка, контролируется ли текущая страна игроком-хостом.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]Переключатель неограниченных инструментов:[/url][/b] Ограничивайте доступ к определенным функциям через настройку «Enable Unrestricted Tools» (триггер cmf_can_use_unrestricted_tools, флаг для каждой настройки cmm_set_requires_unrestricted_tools_enabled). Доступно только для хоста в мультиплеере.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]Определение модов:[/url][/b] Проверка активности другого мода с помощью триггера cmf_is_mod_active.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]Эффект cmf_suppress:[/url][/b] Подавление предупреждений движка «used but never set» и «set but never used» одним вызовом эффекта.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]GUI-макросы:[/url][/b] Макросы логических операторов Nand, Nor и Xor.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Improved-Vanilla-Top-Level-Widget-Overrides]Улучшенная перезапись стандартных виджетов:[/url][/b] Перезаписывайте ванильные виджеты верхнего уровня (lateralviews, topbar, записи аутлайнера и др.) без необходимости копирования каждого типа и шаблона из исходного файла. CMF включает извлеченные определения, поэтому вашей перезаписи нужен только сам виджет.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]Хуки On-Action:[/url][/b] Хуки для старта игры после лобби и загрузки сохранений (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) с вариантами для страны игрока. Также включает общие ежегодные и ежемесячные импульсы (pulses) для игроков-людей.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/cmf_change_variable_map-Effect]Утилиты для карт переменных:[/url][/b] Безопасные помощники для изменения карт переменных (cmf_change_variable_map и локальные/глобальные варианты).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]Журнал действий мода:[/url][/b] Глобальный внутриигровой лог для записи действий мода (например, действий инструментов хоста в мультиплеере, так как лог невозможно очистить в МП).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Сопутствующий набор инструментов разработки, таких как шаблон мода, загрузчик в Workshop и переводчик модов.
[/list]
