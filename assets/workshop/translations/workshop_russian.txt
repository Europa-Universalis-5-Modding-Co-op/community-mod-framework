[b]Community Mod Framework (CMF)[/b] — это вспомогательная модификация, целью которой является улучшение совместимости модов и предоставление разработчикам инструментов для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/banner.png[/img]

[b]CMF должен загружаться первым в вашем списке загрузки модов.[/b]

Если у вас есть вопросы, не стесняйтесь обращаться в Discord EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b]Community Mod Menu (CMM):[/b] Общее внутриигровое меню модов. Авторы модов регистрируют настройки динамически через простой API, без необходимости создавать собственный интерфейс настроек.
  [list]
   [*]Переключатели, кнопки, числовые значения, ползунки (двойной клик для перетаскивания), выпадающие списки, текстовые поля (только для одиночной игры) и списки.
   [*]Вкладки для каждого мода, группы и поиск.
   [*]Глобальные настройки с возможностью редактирования только хостом в мультиплеере.
   [*]Сброс к значениям по умолчанию.
   [*]Перетаскиваемое окно.
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: браузерный инструмент для создания меню вашего мода.
  [/list]
 [*][b]Пользовательские оповещения:[/b] Создание и отображение собственных оповещений в панели уведомлений с помощью ключей локализации.
 [*][b]Панель действий (Action Bar):[/b] Добавление настраиваемых кнопок на панель действий с ключами локализации.
 [*][b]Перенос страны:[/b] Настройки CMM автоматически переносятся при смене страны (смена тега, наследование и т. д.).
 [*][b]Триггер is_host:[/b] Проверка, управляется ли текущая страна игроком-хостом.
 [*][b]Неограниченные инструменты (Unrestricted Tools):[/b] Ограничение доступа к закрытым функциям через главную настройку «Enable Unrestricted Tools» (триггер cmf_can_use_unrestricted_tools, флаг для каждой настройки cmm_set_requires_unrestricted_tools_enabled).
 [*][b]Эффект cmf_suppress:[/b] Подавление предупреждений движка «used but never set» (используется, но не задано) и «set but never used» (задано, но не используется) одним вызовом эффекта.
 [*][b]Хуки On-Action:[/b] Обработчики для старта игры после лобби и загрузки сохранения (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) с вариантами для страны игрока. Также включает общие ежегодные и ежемесячные «пульсы» для живых игроков.
 [*][b]Утилиты карт переменных (Variable Map):[/b] Вспомогательные функции для безопасного изменения карт переменных (cmf_change_variable_map и локальные/глобальные варианты), которые атомарно обрабатывают удаление и последующее добавление.
 [*][b]Журнал (Log):[/b] Глобальный внутриигровой лог для записи действий мода с указанием страны-исполнителя, текста действия и дополнительных аргументов.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Сопутствующий набор инструментов для разработки, таких как шаблон мода, загрузчик в Workshop и переводчик модов.
[/list]
