Фреймворк сообщества для модов — 1.3 Павия / Community Mod Framework - 1.3 Pavia

[b]Community Mod Framework (CMF)[/b] — это служебная модификация, цель которой — улучшить совместимость модов и предоставить моддерам инструменты для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF должен загружаться первым в вашем списке модов.[/b]

Если у вас есть вопросы, обращайтесь в Discord-сообщество EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Функции[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]Community Mod Menu (CMM):[/url][/b] Общее внутриигровое меню модов. Авторы модов регистрируют настройки динамически через простой API.
  [list]
   [*]Переключатели, кнопки, числовые значения, ползунки (двойной клик для перетаскивания), выпадающие списки, текст (только для одиночной игры) и настройки в виде списков
   [*]Вкладки для каждого мода, группы и поиск
   [*]Глобальные настройки с возможностью редактирования только хостом в мультиплеере
   [*]Сброс до настроек по умолчанию (для всех модов или только для выбранного)
   [*]Перемещаемое окно
   [*]Можно открыть через меню паузы в игре или с помощью горячей клавиши (по умолчанию «m», можно переназначить).
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: браузерный инструмент для создания меню вашего мода
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]Custom Alerts:[/url][/b] Создавайте и отображайте кастомные оповещения в панели уведомлений с помощью ключей локализации.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]Action Bar:[/url][/b] Добавляйте кастомные кнопки на панель действий с помощью ключей локализации.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Banners]Mod Banners:[/url][/b] Отображайте ваш мод в виде баннера в лобби перед игрой с иконкой, названием и описанием. Подключается через cmf_register_lobby_banner.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]Country Transfer:[/url][/b] Настройки CMM автоматически переносятся при смене страны (смена тега, наследование и т. д.).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]is_host Trigger:[/url][/b] Проверка, управляется ли текущая страна игроком-хостом.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]Unrestricted Tools Toggle:[/url][/b] Ограничивайте доступ к функциям настройкой «Включить неограниченные инструменты» (триггер cmf_can_use_unrestricted_tools, флаг cmm_set_requires_unrestricted_tools_enabled для отдельных настроек). Доступно только хосту в мультиплеере.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]Mod Detection:[/url][/b] Проверяйте активность других модов с помощью триггера cmf_is_mod_active.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]cmf_suppress Effect:[/url][/b] Подавляйте предупреждения движка «используется, но не задано» (used but never set) и «задано, но не используется» (set but never used) одним вызовом эффекта.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]GUI Macros:[/url][/b] Макросы логических операторов Nand, Nor и Xor.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]On-Action Hooks:[/url][/b] Хуки начала игры после лобби и загрузки сохранения (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) с вариантами для страны игрока. Также включает общие ежегодные и ежемесячные импульсы для игроков-людей.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/cmf_change_variable_map-Effect]Variable Map Utilities:[/url][/b] Вспомогательные функции для безопасного изменения карт переменных (cmf_change_variable_map и локальные/глобальные варианты).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]Mod Action Log:[/url][/b] Глобальный внутриигровой лог для записи действий модов (например, действий хоста в мультиплеере, так как лог в сетевой игре невозможно очистить).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Сопутствующий набор инструментов разработки, включающий шаблон мода, загрузчик в мастерскую и переводчик модов.
[/list]
