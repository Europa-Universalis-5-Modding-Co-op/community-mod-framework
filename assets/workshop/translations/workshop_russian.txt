[b]Community Mod Framework (CMF)[/b] — это вспомогательный мод, целью которого является улучшение совместимости модов и предоставление моддерам инструментов для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF должен загружаться первым в вашем списке загрузки модов.[/b]

По любым вопросам обращайтесь в Discord-сервер EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]Community Mod Menu (CMM):[/url][/b] Общее внутриигровое меню модов. Авторы модов регистрируют настройки динамически через простой API, без необходимости создавать собственный интерфейс настроек.
  [list]
   [*]Переключатели, кнопки, числовые поля, ползунки (двойной клик для перетаскивания), выпадающие списки, текстовые поля (только для одиночной игры) и настройки списков.
   [*]Вкладки для каждого мода, группы и поиск.
   [*]Глобальные настройки с возможностью редактирования только хостом в мультиплеере.
   [*]Сброс к настройкам по умолчанию.
   [*]Перетаскиваемое окно.
   [*]Можно открыть из меню паузы в игре или с помощью горячей клавиши (по умолчанию 'm', можно переназначить).
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: браузерный инструмент для визуального создания меню вашего мода.
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]Настраиваемые оповещения:[/url][/b] Создавайте и отображайте собственные оповещения в панели уведомлений с помощью ключей локализации.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]Панель действий:[/url][/b] Добавляйте собственные кнопки на панель действий с помощью ключей локализации.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]Перенос страны:[/url][/b] Настройки CMM автоматически переносятся при смене страны (смена тега, наследование и т. д.).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]Триггер is_host:[/url][/b] Проверка, управляется ли текущая страна игроком-хостом.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]Переключатель неограниченных инструментов:[/url][/b] Ограничение доступа к определенным функциям настройкой «Включить неограниченные инструменты» (триггер cmf_can_use_unrestricted_tools, флаг cmm_set_requires_unrestricted_tools_enabled для отдельных настроек). Доступно только для хоста в мультиплеере.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]Эффект cmf_suppress:[/url][/b] Подавление предупреждений движка «используется, но не задано» и «задано, но не используется» одним вызовом эффекта.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]GUI-макросы:[/url][/b] Макросы логических операторов Nand, Nor и Xor.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]Хуки On-Action:[/url][/b] Хуки для старта игры после лобби и загрузки сохранения (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) с вариантами для стран игроков. Также включает общие ежегодные и ежемесячные «пульсы» для живых игроков.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/cmf_change_variable_map-Effect]Утилиты карт переменных:[/url][/b] Вспомогательные функции для безопасного изменения карт переменных (cmf_change_variable_map и локальные/глобальные варианты), которые атомарно обрабатывают удаление и последующее добавление.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]Журнал действий мода:[/url][/b] Глобальный внутриигровой журнал для записи действий мода (например, действий инструментов хоста в мультиплеере, так как журнал нельзя очистить в сетевой игре).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Сопутствующий набор инструментов разработки, таких как шаблон мода, загрузчик в Workshop и переводчик модов.
[/list]
