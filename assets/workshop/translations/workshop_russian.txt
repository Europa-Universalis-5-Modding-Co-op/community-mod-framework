[b]Community Mod Framework (CMF)[/b] — это вспомогательная модификация, целью которой является улучшение взаимодействия между модами и предоставление моддерам инструментов для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF должен загружаться первым в вашем списке загрузки модов.[/b]

Если у вас есть вопросы, обращайтесь в Discord-сообщество EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]Community Mod Menu (CMM):[/url][/b] Общее игровое меню модов. Авторы модов динамически регистрируют настройки через простой API.
  [list]
   [*]Переключатели, кнопки, числовые значения, ползунки (двойной клик для перетаскивания), выпадающие списки, текстовые поля (только для одиночной игры) и списки.
   [*]Вкладки для каждого мода, подвкладки, группы и поиск.
   [*]Сворачиваемые группы настроек.
   [*]Глобальные настройки с возможностью редактирования только хостом в мультиплеере.
   [*]Сброс к значениям по умолчанию (для всех модов или только для выбранного).
   [*]Перемещаемое окно.
   [*]Меню можно открыть из меню паузы (Esc) или с помощью горячей клавиши (по умолчанию «m», можно переназначить).
   [*]Меню открывается без выбранной страны, в лобби выбора страны и в режиме наблюдателя, отображая значения вашей последней страны. Настройки нельзя изменить, пока вы не выберете страну.
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: браузерный инструмент для создания меню вашего мода.
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]Кастомные оповещения:[/url][/b] Создавайте и отображайте собственные оповещения в панели оповещений через ключи локализации, с настраиваемыми действиями по левому клику, а также возможностью скрытия и отключения звука в стиле ванильной игры.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]Панель действий:[/url][/b] Добавляйте кастомные кнопки на панель действий с ключами локализации.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Banners]Баннеры модов:[/url][/b] Отображайте ваш мод в виде баннера в лобби перед началом игры с иконкой, названием и описанием. Активируется через cmf_register_lobby_banner.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]Перенос страны:[/url][/b] Настройки CMM автоматически переносятся при смене страны (смена тега, наследование и т. д.).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]Триггер is_host:[/url][/b] Проверка того, управляется ли текущая страна игроком-хостом.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]Переключатель неограниченных инструментов:[/url][/b] Ограничивайте доступ к расширенным функциям через настройку «Включить неограниченные инструменты» (триггер cmf_can_use_unrestricted_tools, флаг cmm_set_requires_unrestricted_tools_enabled для отдельных настроек). Доступно только хосту в мультиплеере.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]Обнаружение модов:[/url][/b] Проверка активности другого мода с помощью триггера cmf_is_mod_active или проверка того, был ли он активен на момент запуска игры через cmf_was_mod_active_at_game_start.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]Эффект cmf_suppress:[/url][/b] Подавление предупреждений движка «used but never set» и «set but never used» одним вызовом эффекта.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]Макросы GUI:[/url][/b] Макросы для логических операторов Nand, Nor и Xor.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Improved-Vanilla-Top-Level-Widget-Overrides]Улучшенное переопределение ванильных виджетов:[/url][/b] Переопределяйте ванильные виджеты верхнего уровня (lateralviews, topbar, записи в планировщике и др.) без необходимости копирования всех типов и шаблонов из исходного файла. CMF включает извлеченные определения, поэтому вашему переопределению нужен только сам виджет.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]Хуки On-Action:[/url][/b] Хуки загрузки сохранений (on_game_load, on_game_load_after_lobby) и варианты для игроков при старте игры и загрузке. Также включает общие ежегодные и ежемесячные импульсы (pulses) для игроков-людей.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]Лог действий мода:[/url][/b] Глобальный внутриигровой лог для записи действий модов (например, действий инструментов хоста в мультиплеере, так как этот лог невозможно очистить в сетевой игре).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Сопутствующий набор инструментов разработки, включающий шаблон мода, загрузчик в Workshop и переводчик модов.
[/list]
