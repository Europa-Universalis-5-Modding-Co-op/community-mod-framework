[b]Community Mod Framework (CMF)[/b] — это вспомогательный мод, целью которого является улучшение совместимости модов при одновременном предоставлении моддерам инструментов для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF должен загружаться первым в вашем порядке загрузки модов.[/b]

По любым вопросам обращайтесь в EU5 Mod Coop Discord: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Community-Mod-Menu]Общее меню модов (CMM):[/url][/b] Общее внутриигровое меню модов. Авторы модов регистрируют настройки динамически через простой API.
  [list]
   [*]Переключатели, кнопки, числовые поля, ползунки (двойной клик для перемещения), выпадающие списки, текстовые поля (только для одиночной игры) и настройки списков.
   [*]Вкладки для каждого мода, группы и поиск.
   [*]Глобальные настройки с возможностью редактирования в мультиплеере только хостом.
   [*]Сброс к значениям по умолчанию (для всех модов или только для выбранного).
   [*]Перетаскиваемое окно.
   [*]Можно открыть из меню паузы (escape) в игре. Или с помощью горячей клавиши (по умолчанию 'm', можно переназначить).
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: браузерный инструмент для создания вашего меню мода.
  [/list]
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Custom-Alerts]Пользовательские оповещения:[/url][/b] Создавайте и отображайте пользовательские оповещения на панели уведомлений с помощью ключей локализации.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Action-Bar]Панель действий:[/url][/b] Добавляйте пользовательские кнопки на панель действий с помощью ключей локализации.
 [*][b]Демонстрация модов:[/b] Отображайте свой мод в виде баннера на экране лобби перед игрой с иконкой, названием и описанием. Подключается через cmf_register_lobby_banner.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks#country-transfer]Перенос страны:[/url][/b] Настройки CMM автоматически переносятся при смене страны (смена тега, наследование и т. д.).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger]Триггер is_host:[/url][/b] Проверяет, контролируется ли текущая страна игроком-хостом.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/is_host-Trigger#cmf_can_use_unrestricted_tools]Переключатель неограниченных инструментов:[/url][/b] Ограничивайте доступ к определенным функциям через настройку "Enable Unrestricted Tools" (триггер cmf_can_use_unrestricted_tools, флаг настройки cmm_set_requires_unrestricted_tools_enabled). Доступно только для хоста в мультиплеере.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Detection]Обнаружение модов:[/url][/b] Проверяйте, активен ли другой мод с помощью триггера cmf_is_mod_active.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Warning-Suppression]Эффект cmf_suppress:[/url][/b] Подавляйте предупреждения движка "used but never set" и "set but never used" одним вызовом эффекта.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/GUI-Macros]Макросы GUI:[/url][/b] Логические операторы Nand, Nor и Xor для макросов интерфейса.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/On-Action-Hooks]Хуки On-Action:[/url][/b] Хуки начала игры после лобби и загрузки сохранения (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) с вариантами для страны игрока. Также включает общие ежегодные и ежемесячные импульсы для игроков-людей.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/cmf_change_variable_map-Effect]Утилиты карты переменных:[/url][/b] Помощники для безопасного изменения карт переменных (cmf_change_variable_map и локальные/глобальные варианты).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/Mod-Action-Log]Журнал действий мода:[/url][/b] Глобальный внутриигровой журнал для записи действий мода (например, действий инструментов хоста в мультиплеере, так как журнал невозможно очистить в сетевой игре).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Сопутствующий набор инструментов разработки, таких как шаблон мода, загрузчик в Workshop и переводчик модов.
[/list]
