[b]Community Mod Framework (CMF)[/b] — это служебная модификация, цель которой — улучшить совместимость модов и предоставить моддерам инструменты для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/banner.png[/img]

[b]CMF должен загружаться первым в вашем списке порядка загрузки модов.[/b]

По любым вопросам обращайтесь в Discord EU5 Mod Coop: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b]Community Mod Menu (CMM):[/b] Общее внутриигровое меню модов. Авторы модов динамически регистрируют настройки через простой API — нет необходимости создавать собственный интерфейс настроек.
  [list]
   [*]Переключатели, кнопки, числовые значения, ползунки (двойной клик для перетаскивания), выпадающие списки, текстовые поля (только для одиночной игры) и списки настроек
   [*]Вкладки для каждого мода, группы и поиск
   [*]Глобальные настройки с возможностью редактирования только хостом в мультиплеере
   [*]Сброс до настроек по умолчанию
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url] — браузерный инструмент для создания вашего меню мода
  [/list]
 [*][b]Пользовательские оповещения:[/b] Создавайте и отображайте собственные оповещения на панели уведомлений с помощью ключей локализации.
 [*][b]Панель действий:[/b] Добавляйте пользовательские кнопки на панель действий с помощью ключей локализации.
 [*][b]Триггер is_host:[/b] Проверяет, управляется ли текущая страна игроком-хостом.
 [*][b]Эффект cmf_suppress:[/b] Подавляйте предупреждения движка "used but never set" и "set but never used" одним вызовом эффекта.
 [*][b]Хук страны игрока:[/b] Общие on_actions (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse), которые срабатывают для страны каждого игрока-человека на ежегодных и ежемесячных импульсах (чуть более эффективно, чем если бы каждый мод проверял наличие игроков по отдельности).
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Набор сопутствующих инструментов для разработки, таких как шаблон мода, загрузчик в мастерскую и переводчик модов.
[/list]
