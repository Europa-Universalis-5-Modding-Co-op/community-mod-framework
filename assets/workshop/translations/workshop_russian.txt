[b]Community Mod Framework (CMF)[/b] — это служебный мод, целью которого является улучшение совместимости модов и предоставление мододелам инструментов для создания новых функций.

[img]https://raw.githubusercontent.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/main/assets/images/cmf/CMF_Banner.png[/img]

[b]CMF должен загружаться первым в вашем списке модов.[/b]

По любым вопросам обращайтесь в EU5 Mod Coop Discord: https://discord.gg/aqAAcCZsY7

[h1]Особенности[/h1]
[list]
 [*][b]Community Mod Menu (CMM):[/b] Общее внутриигровое меню модов. Авторы модов регистрируют настройки динамически через простой API, без необходимости создавать собственный интерфейс настроек.
  [list]
   [*]Переключатели, кнопки, числовые значения, ползунки (двойной клик для перемещения), выпадающие списки, текстовые поля (только для одиночной игры) и списки настроек.
   [*]Вкладки для отдельных модов, группы и поиск.
   [*]Глобальные настройки с возможностью редактирования только хостом в мультиплеере.
   [*]Сброс к значениям по умолчанию.
   [*]Перетаскиваемое окно.
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url]: браузерный инструмент для создания меню вашего мода.
  [/list]
 [*][b]Пользовательские оповещения:[/b] Создавайте и отображайте собственные оповещения в панели оповещений через ключи локализации.
 [*][b]Панель действий:[/b] Добавляйте пользовательские кнопки на панель действий с помощью ключей локализации.
 [*][b]Перенос страны:[/b] Настройки CMM автоматически переносятся при смене страны (смена тега, наследование и т. д.).
 [*][b]Триггер is_host:[/b] Проверяет, контролируется ли текущая страна игроком-хостом.
 [*][b]Неограниченные инструменты:[/b] Ограничивайте доступ к определенным функциям через мастер-настройку «Enable Unrestricted Tools» (триггер cmf_can_use_unrestricted_tools, флаг настройки cmm_set_requires_unrestricted_tools_enabled для каждой отдельной настройки).
 [*][b]Эффект cmf_suppress:[/b] Подавляйте предупреждения движка «used but never set» и «set but never used» одним вызовом эффекта.
 [*][b]GUI-макросы:[/b] Макросы логических операторов Nand, Nor и Xor.
 [*][b]Хуки On-Action:[/b] Хуки для старта игры после лобби и загрузки сохранений (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby) с вариантами для стран игроков. Также включает общие ежегодные и ежемесячные импульсы (pulses) для живых игроков.
 [*][b]Утилиты карт переменных (Variable Map):[/b] Вспомогательные функции для безопасного изменения карт переменных (cmf_change_variable_map и локальные/глобальные варианты), которые атомарно обрабатывают удаление и последующее добавление.
 [*][b]Журнал (Log):[/b] Глобальный внутриигровой лог для записи действий модов с указанием страны-актора, текста действия и дополнительных аргументов.
 [*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Сопутствующий набор инструментов разработки, таких как шаблон мода, загрузчик в Workshop и переводчик модов.
[/list]
