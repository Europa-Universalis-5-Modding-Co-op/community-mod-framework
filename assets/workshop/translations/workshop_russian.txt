[h1]Community Mod Framework[/h1]

[b]Community Mod Framework (CMF)[/b] — это общая вспомогательная модификация, предоставляющая меню настроек и инструменты для создания модов для Europa Universalis V.

[b]CMF должен загружаться первым в вашем списке модификаций.[/b]

[h1]Особенности[/h1]
[list]
[*][b]Community Mod Menu (CMM):[/b] Общее внутриигровое окно настроек модов. Авторы модов регистрируют настройки динамически через простой API — нет необходимости создавать собственный интерфейс.
  [list]
   [*]Переключатели, кнопки, числовые значения, ползунки (двойной клик для перетаскивания), выпадающие списки, текст (только для одиночной игры) и списки.
   [*]Вкладки для каждого мода, группы и поиск.
   [*]Глобальные настройки с возможностью редактирования только хостом в мультиплеере.
   [*]Сброс настроек по умолчанию.
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url] — браузерный инструмент для создания настроек без написания кода.
  [/list]
[*][b]Custom Alerts:[/b] Создание и отображение пользовательских оповещений в панели оповещений через ключи локализации.
[*][b]Action Bar:[/b] Добавление пользовательских кнопок на панель действий с помощью ключей локализации.
[*][b]is_host Trigger:[/b] Проверка, управляется ли текущая страна игроком-хостом.
[*][b]cmf_suppress Effect:[/b] Подавление предупреждений движка «used but never set» и «set but never used» одним вызовом эффекта.
[*][b]Player Country Hook:[/b] Общие on_actions (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse), которые срабатывают для каждой страны под управлением игрока в ежегодных и ежемесячных циклах (это эффективнее, чем если бы каждый мод проверял наличие игроков по отдельности).
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Набор инструментов для разработки, включающий шаблон мода, загрузчик в Workshop и переводчик модов.
[/list]
