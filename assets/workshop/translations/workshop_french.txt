[h1]Community Mod Framework[/h1]

Le [b]Community Mod Framework (CMF)[/b] est un mod utilitaire partagé qui fournit un menu de mod et des outils de développement pour Europa Universalis V.

[b]Le CMF doit être chargé en premier dans l'ordre de chargement de vos mods.[/b]

[h1]Fonctionnalités[/h1]
[list]
[*][b]Community Mod Menu (CMM) :[/b] Une fenêtre de paramètres de mod partagée en jeu. Les auteurs de mods enregistrent les paramètres de manière dynamique via une API simple — plus besoin de créer une interface utilisateur de paramètres personnalisée.
  [list]
   [*]Paramètres de type bascule, bouton, numérique, curseur (double-cliquer pour faire glisser), menu déroulant, texte (solo uniquement) et liste.
   [*]Onglets par mod, groupes et recherche.
   [*]Paramètres globaux avec modification réservée à l'hôte en multijoueur.
   [*]Réinitialisation aux valeurs par défaut.
   [*]Outil CMM Visual Editor pour une configuration sans code.
  [/list]
[*][b]Alertes personnalisées :[/b] Créez et affichez des alertes personnalisées dans la barre d'alertes via des clés de localisation.
[*][b]Barre d'action :[/b] Ajoutez des boutons personnalisés à la barre d'action avec des clés de localisation.
[*][b]Trigger is_host :[/b] Vérifie si le pays actuel est contrôlé par l'hôte.
[*][b]Effet cmf_suppress :[/b] Supprime les avertissements du moteur « used but never set » et « set but never used » avec un seul appel d'effet.
[*][b]Hook de pays joueur :[/b] on_actions partagés (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse) qui se déclenchent pour le pays de chaque joueur humain lors des impulsions annuelles et mensuelles (légèrement plus efficace que si chaque mod vérifiait les joueurs individuellement).
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT) :[/url][/b] Un ensemble d'outils de développement complémentaires, tels qu'un modèle de mod, un outil d'upload vers le workshop et un traducteur de mod.
[/list]
