- [b]Меню модов сообщества (CMM):[/b] Общее внутриигровое окно настроек модов, поддерживающее переключатели, кнопки, числовые значения, ползунки (двойной клик для перемещения), выпадающие списки, текстовые поля (только для одиночной игры) и списки настроек. Включает вкладки для отдельных модов, группы, поиск, глобальные настройки с возможностью редактирования только хостом в мультиплеере и функцию сброса настроек по умолчанию.
- [b]Визуальный редактор CMM:[/b] Браузерный инструмент для создания конфигураций CMM без ручного написания кода. Включает предпросмотр в реальном времени и изменение порядка элементов перетаскиванием.
- [b]Триггер is_host:[/b] Проверяет, управляется ли текущая страна игроком-хостом.
- [b]Эффект cmf_suppress:[/b] Подавляет предупреждения движка «used but never set» и «set but never used» одним вызовом эффекта.
- [b]Хуки для стран игроков:[/b] Общие on_actions (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse), которые срабатывают для страны каждого игрока-человека во время ежегодных и ежемесячных импульсов.
- [b]Инструментарий модов сообщества (CMT):[/b] Вспомогательные инструменты разработки — шаблон мода, загрузчик в Workshop и автоматический перевод.
- [b]Унифицированная система обратных вызовов:[/b] Пользовательские оповещения и панель действий теперь используют единый on_action cmf_on_callback.
- [b]Scripted GUI больше не требуются:[/b] Оповещениям и элементам панели действий Scripted GUI нужен только для условий видимости или активного состояния.
