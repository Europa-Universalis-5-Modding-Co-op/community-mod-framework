- [b]Хуки событий (On-Action) после лобби:[/b] Новые хуки жизненного цикла (on_game_start_after_lobby, on_game_load, on_game_load_after_lobby), которые срабатывают после выбора страны, включая варианты для стран игроков. Решает ограничение ванильной игры, при котором on_game_start срабатывает до лобби.
- [b]Авто-активатор мода:[/b] Всплывающее окно проверки зависимостей в главном меню, которое автоматически активирует CMF или открывает Workshop, если он отсутствует.
- [b]Отключение полей для отдельных элементов списка:[/b] Скрытие определенных колонок полей для конкретных элементов в настройках списка (cmm_disable_list_field_for_item / cmm_enable_list_field_for_item).
- [b]Утилиты для карт переменных (Variable Map):[/b] Новые эффекты cmf_change_variable_map, cmf_change_local_variable_map и cmf_change_global_variable_map для безопасного изменения карт переменных.
- [b]Исправления ошибок:[/b] Исправлен скоупинг ежемесячных/ежегодных хуков и ошибки неопределенных областей видимости (unset scope).
- [b]Визуальный редактор CMM (v1.1.0):[/b] Добавлена поддержка отключения полей для отдельных элементов и исправлено именование шаблонного кода при итерации списков.
