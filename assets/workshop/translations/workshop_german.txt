[h1]Community Mod Framework[/h1]

Das [b]Community Mod Framework (CMF)[/b] ist eine geteilte Utility-Mod, die ein Mod-Menü und Modding-Tools für Europa Universalis V bereitstellt.

[b]Das CMF sollte in deiner Mod-Ladereihenfolge an erster Stelle geladen werden.[/b]

[h1]Features[/h1]
[list]
[*][b]Community Mod Menu (CMM):[/b] Ein gemeinsames Fenster für Mod-Einstellungen im Spiel. Mod-Autoren registrieren Einstellungen dynamisch über eine einfache API — eine eigene Einstellungs-Benutzeroberfläche muss nicht erstellt werden.
  [list]
   [*]Umschalter, Schaltflächen, numerische Werte, Schieberegler (Doppelklick zum Ziehen), Dropdown-Menüs, Text (nur im Einzelspieler) und Listen-Einstellungen
   [*]Tabs pro Mod, Gruppen und Suchfunktion
   [*]Globale Einstellungen mit Bearbeitung nur durch den Host im Mehrspieler
   [*]Auf Standardeinstellungen zurücksetzen
   [*]CMM Visual Editor-Tool für die Einrichtung ohne Code
  [/list]
[*][b]Benutzerdefinierte Alarme:[/b] Erstelle und zeige eigene Benachrichtigungen in der Alarmleiste mithilfe von Lokalisierungsschlüsseln an.
[*][b]Aktionsleiste:[/b] Füge der Aktionsleiste benutzerdefinierte Schaltflächen mit Lokalisierungsschlüsseln hinzu.
[*][b]is_host Trigger:[/b] Prüft, ob das aktuelle Land vom Host-Spieler gesteuert wird.
[*][b]cmf_suppress Effekt:[/b] Unterdrücke Engine-Warnungen wie „used but never set“ und „set but never used“ mit einem einzigen Effekt-Aufruf.
[*][b]Player Country Hook:[/b] Gemeinsame on_actions (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse), die für jedes Land eines menschlichen Spielers bei jährlichen und monatlichen Pulsen ausgelöst werden (etwas effizienter, als wenn jede Mod einzeln nach Spielern prüft).
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Eine ergänzende Sammlung von Entwicklungswerkzeugen, wie eine Mod-Vorlage, ein Workshop-Uploader und ein Mod-Übersetzer.
[/list]
