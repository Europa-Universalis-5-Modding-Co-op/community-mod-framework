[h1]Community Mod Framework[/h1]

Das [b]Community Mod Framework (CMF)[/b] ist eine gemeinsame Hilfs-Mod, die ein Mod-Menü und Modding-Werkzeuge für Europa Universalis V bereitstellt.

[b]CMF sollte in deiner Mod-Ladereihenfolge an erster Stelle geladen werden.[/b]

[h1]Features[/h1]
[list]
[*][b]Community Mod Menu (CMM):[/b] Ein gemeinsames Fenster für Mod-Einstellungen im Spiel. Mod-Autoren registrieren Einstellungen dynamisch über eine einfache API – es ist nicht nötig, eine eigene Benutzeroberfläche für Einstellungen zu erstellen.
  [list]
   [*]Umschalter, Schaltflächen, numerische Werte, Schieberegler (Doppelklick zum Ziehen), Dropdowns, Text (nur Einzelspieler) und Listeneinstellungen
   [*]Tabs pro Mod, Gruppen und Suche
   [*]Globale Einstellungen mit Bearbeitung nur durch den Host im Mehrspielermodus
   [*]Auf Standardwerte zurücksetzen
   [*]CMM Visual Editor Werkzeug für die Einrichtung ohne Code
  [/list]
[*][b]Benutzerdefinierte Warnungen:[/b] Erstelle und zeige benutzerdefinierte Warnungen in der Warnleiste über Lokalisierungsschlüssel an.
[*][b]Aktionsleiste:[/b] Füge benutzerdefinierte Schaltflächen für die Aktionsleiste mit Lokalisierungsschlüsseln hinzu.
[*][b]is_host Trigger:[/b] Überprüft, ob das aktuelle Land vom Host-Spieler gesteuert wird.
[*][b]cmf_suppress Effekt:[/b] Unterdrücke „used but never set“ und „set but never used“ Engine-Warnungen mit einem einzigen Effekt-Aufruf.
[*][b]Player Country Hook:[/b] Gemeinsame on_actions (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse), die für jedes Land eines menschlichen Spielers bei jährlichen und monatlichen Pulsen ausgelöst werden (etwas effizienter, als wenn jede Mod einzeln nach Spielern sucht).
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Ein begleitendes Set von Entwicklungswerkzeugen, wie eine Mod-Vorlage, ein Workshop-Uploader und ein Mod-Übersetzer.
[/list]
