[h1]Community Mod Framework[/h1]

Das [b]Community Mod Framework (CMF)[/b] ist eine gemeinschaftliche Utility-Mod, die ein Mod-Menü und Modding-Tools für Europa Universalis V bereitstellt.

[b]Das CMF sollte in deiner Mod-Ladereihenfolge an erster Stelle geladen werden.[/b]

[h1]Features[/h1]
[list]
[*][b]Community Mod Menu (CMM):[/b] Ein gemeinsames In-Game-Einstellungsfenster für Mods. Mod-Autoren registrieren Einstellungen dynamisch über eine einfache API – es ist nicht nötig, eine eigene Benutzeroberfläche für Einstellungen zu erstellen.
  [list]
   [*]Schalter, Schaltflächen, numerische Werte, Schieberegler (Doppelklick zum Ziehen), Dropdowns, Text (nur Einzelspieler) und Listen-Einstellungen
   [*]Tabs pro Mod, Gruppen und Suche
   [*]Globale Einstellungen mit Bearbeitung nur durch den Host im Mehrspielermodus
   [*]Auf Standardwerte zurücksetzen
   [*]CMM Visual Editor Tool für ein Setup ohne Programmierung
  [/list]
[*][b]Benutzerdefinierte Benachrichtigungen:[/b] Erstelle und zeige benutzerdefinierte Benachrichtigungen in der Alarmleiste mithilfe von Lokalisierungsschlüsseln an.
[*][b]Aktionsleiste:[/b] Füge benutzerdefinierte Schaltflächen zur Aktionsleiste mit Lokalisierungsschlüsseln hinzu.
[*][b]is_host Trigger:[/b] Prüft, ob das aktuelle Land vom Host-Spieler kontrolliert wird.
[*][b]cmf_suppress Effekt:[/b] Unterdrückt Engine-Warnungen wie „used but never set“ und „set but never used“ mit einem einzigen Effekt-Aufruf.
[*][b]Player Country Hook:[/b] Gemeinsame on_actions (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse), die für jedes Land eines menschlichen Spielers bei jährlichen und monatlichen Pulsen ausgelöst werden (etwas effizienter, als wenn jede Mod einzeln nach Spielern prüft).
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Eine begleitende Sammlung von Entwicklungswerkzeugen, wie eine Mod-Vorlage, ein Workshop-Uploader und ein Mod-Übersetzer.
[/list]
