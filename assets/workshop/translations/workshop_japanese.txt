[h1]Community Mod Framework[/h1]

[b]Community Mod Framework (CMF)[/b] は、Europa Universalis V のためのモッドメニューとモッディングツールを提供する、共有のユーティリティモッドです。

[b]CMF はモッドのロード順の最初に読み込む必要があります。[/b]

[h1]機能[/h1]
[list]
[*][b]Community Mod Menu (CMM):[/b] ゲーム内の共有モッド設定ウィンドウ。モッド制作者はシンプルな API を通じて動的に設定を登録でき、カスタムの設定 UI を構築する必要はありません。
  [list]
   [*]トグル、ボタン、数値、スライダー（ダブルクリックでドラッグ可能）、ドロップダウン、テキスト（シングルプレイヤー限定）、およびリスト設定
   [*]モッドごとのタブ、グループ、および検索機能
   [*]マルチプレイヤーでのホスト限定編集が可能なグローバル設定
   [*]デフォルトにリセット
   [*][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-framework/wiki/CMM-Visual-Editor]CMM Visual Editor[/url] — コーディング不要で設定を作成できるブラウザベースのツール
  [/list]
[*][b]カスタムアラート:[/b] ローカライズキーを使用して、アラートバーにカスタムアラートを作成し表示します。
[*][b]アクションバー:[/b] ローカライズキーを使用して、カスタムのアクションバーボタンを追加します。
[*][b]is_host トリガー:[/b] 現在の国家がホストプレイヤーによって操作されているかどうかを確認します。
[*][b]cmf_suppress エフェクト:[/b] 単一のエフェクト呼び出しで、エンジンの「使用されているが設定されていない（used but never set）」および「設定されているが使用されていない（set but never used）」警告を抑制します。
[*][b]プレイヤー国家フック:[/b] 各人間プレイヤーの国家に対して、年次および月次のパルスで実行される共有の on_actions (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse)（各モッドが個別にプレイヤーをチェックするよりもわずかに効率的です）。
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] モッドテンプレート、ワークショップアップローダー、モッド翻訳ツールなどの開発ツールセット。
[/list]
