[h1]Community Mod Framework[/h1]

[b]Community Mod Framework (CMF)[/b] は、Europa Universalis V 用の Mod メニューと Mod 制作ツールを提供する、共有のユーティリティ Mod です。

[b]CMF は Mod のロード順の最優先（先頭）に読み込む必要があります。[/b]

[h1]機能[/h1]
[list]
[*][b]Community Mod Menu (CMM):[/b] ゲーム内共通の Mod 設定ウィンドウ。Mod 開発者はシンプルな API を介して動的に設定を登録でき、独自の設定 UI を構築する必要はありません。
  [list]
   [*]トグル、ボタン、数値、スライダー（ダブルクリックでドラッグ）、ドロップダウン、テキスト（シングルプレイヤー限定）、リスト設定
   [*]Mod ごとのタブ、グループ、および検索機能
   [*]マルチプレイヤーにおいてホストのみが編集可能なグローバル設定
   [*]デフォルトにリセット機能
   [*]コード不要でセットアップできる CMM ビジュアルエディターツール
  [/list]
[*][b]カスタムアラート:[/b] ローカライズキーを使用して、アラートバーにカスタムアラートを作成・表示します。
[*][b]アクションバー:[/b] ローカライズキーを使用して、カスタムのアクションバーボタンを追加します。
[*][b]is_host トリガー:[/b] 現在の国家がホストプレイヤーによって操作されているかを確認します。
[*][b]cmf_suppress エフェクト:[/b] 1 回のエフェクト呼び出しで、エンジンの警告「used but never set」および「set but never used」を抑制します。
[*][b]プレイヤー国家フック:[/b] 各人間プレイヤーの国家に対して、年次および月次パルスごとに実行される共有の on_actions (cmf_yearly_human_country_pulse, cmf_monthly_human_country_pulse) です（各 Mod が個別にプレイヤーをチェックするよりも効率的です）。
[*][b][url=https://github.com/Europa-Universalis-5-Modding-Co-op/community-mod-toolkit]Community Mod Toolkit (CMT):[/url][/b] Mod テンプレート、ワークショップアップローダー、Mod 翻訳ツールなどの開発支援ツールセットです。
[/list]
